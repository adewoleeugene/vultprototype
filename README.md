# Vult Shops prototype

A mobile-first, browser-based product concept showing how a curated merchant marketplace could extend the existing Vult fintech app.

## Run locally

From this folder:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Demo flow

1. Open the featured Drop or Basha Bakery & Restaurant.
2. Add menu items and adjust the cart.
3. Choose collection or illustrative delivery.
4. Continue to the simulated Vult payment.
5. Use **Confirm payment** for success, or **Demo payment failure** to show retry behavior.
6. Use **Reset prototype** at the bottom of Shops Home between presentations.

All transactions are simulated. Secondary merchants and the Vult Drop are explicitly marked as concepts. Basha’s address, menu items, descriptions, and listed prices were drawn from its public website on October 9, 2026; no partnership or endorsement is implied.

The marketplace imagery was generated specifically for this prototype with OpenAI’s built-in image generation tool. Final prompt: a cohesive, photorealistic 4×2 marketplace product contact sheet covering food, fashion, beauty, electronics, and lifestyle, with equal crop-safe tiles, neutral/pale-cyan studio backdrops, and no text, logos, people, or watermark.
